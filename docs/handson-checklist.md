# EasyEDA 직접 진행 체크리스트 (강사용)

강사가 EasyEDA로 정답 보드를 한 번 끝까지 만들면서 **세 가지를 동시에** 얻는 순서표다.
1. 정답 보드 (학생이 막혔을 때 보여 줄 완성본)
2. 실습 슬라이드에 넣을 스크린샷 (덱의 실습 1~17 구간이 지금 비어 있다)
3. 사양서 ⚠ 해소 (특히 핀 번호 대 심볼 대조)

슬라이드 번호는 `slides/PCB설계_RC카 .pptx` 486장 기준이다 ([`deck-outline.md`](deck-outline.md)).

## 0. 시작 전 (10분)

- [ ] [`parts-confirmed.md`](parts-confirmed.md) 1절의 번호를 EasyEDA 부품 검색에 전부 넣어 본다. 검색에 안 나오면 그 행에 표시
- [ ] 특히 △ 부품(MMBT3904, 0603 저항 · 캡 6종)은 사양을 눈으로 확인 (12V 레일 캡은 정격 25V 이상)
- [ ] 전류 제한 회로(Rs + NPN)를 **필수 실습에 넣을지 결정** — 아래 권고 참고

## 3. 권고 (냉정하게)

- **전류 제한 회로는 필수 실습에서 빼는 것을 권한다.** 간이 시뮬레이션만 했고 실물 검증이 없다. 검증 안 된 회로를 학생이 그리게 하면, 틀려도 "정답 보드"가 그렇게 돼 있어서 틀렸다고 말할 수 없다. 이론(stall 전류와 보호 역할)은 그대로 가르치고, 회로는 "완성본에는 있다 / 검증 전"으로 보여 주는 정도가 안전하다. 이 결정은 강사 몫이다.
- 실습 1~17을 학생 손으로 다 하면 시간이 모자랄 가능성이 크다. 이번에 직접 해 보면 **어느 단계가 몇 분 걸리는지** 알게 되므로, 그 값으로 "템플릿 제공 / 학생이 직접" 경계를 정한다. 사양서 8장은 1단계(MCU 코어)를 템플릿으로 주는 안이다.
- MCP 시연은 이 체크리스트에서 제외했다 (덱 458–477).
