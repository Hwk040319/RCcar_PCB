## 강사 메모 (공지에 넣지 않는다)

공지 전에 정할 것
- [ ] EasyEDA 버전 (웹 / 설치형). 덱의 메뉴 경로 슬라이드는 실제 화면을 확인하기 전이다
- [ ] 계정 없이 진행 가능한지, 가입 방식은 무엇인지
- [ ] 노트북 없는 사람을 위한 대안 (있는지)
- [ ] 정원과 학교 / 동아리 와이파이 상태 (EasyEDA 라이브러리는 온라인 검색)

당일 막힐 수 있는 것 (원인 → 대응)
- 로그인 안 됨 → 사전 가입 요청이 이 공지의 핵심 이유
- 부품이 검색에 안 나옴 → 번호 대신 모델명으로 검색. 번호는 [`parts-confirmed.md`](parts-confirmed.md)
- 328PB를 고름 → 모델명 끝이 `328P-AU`인지 확인 (parts-confirmed 2절)
