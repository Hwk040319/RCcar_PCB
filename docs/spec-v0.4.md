## 1. 목표와 범위

**목표**: "컴팩트" = 점퍼선 · Arduino 보드 · L298N 모듈 없이, 한 장의 PCB로 통합한다.

| 구분 | 내용 |
|---|---|
| PCB 위 | MCU(ATmega328P) · 클록 · 리셋 · 전원(12V → 5V → 3.3V) · L298N IC와 보호 회로 · 커넥터 |
| PCB 밖 | nRF24L01+ 모듈(안테나) · VL53L0X 거리센서 · 모터 2개 · 12V 어댑터선(+/− 2선) |
| 범위 밖 | 발주(설계까지만) · 조종기 보드(확장 과제, 9장) |

기존 Mega + L298N 모듈 구성과 다른 점: 12V와 모터 전류가 **PCB를 지난다**. 그래서 선폭 · 벌크 캡 · 역기전력 다이오드 · 발열 · GND 귀환 경로가 모두 이 보드의 일이 된다.

**설계 기준**: 모터 1개 stall 5.5A, 어댑터 12V 5A (6장). 칩(L298N)은 이 전류를 견딜 수 없으므로 **칩은 전류 제한 회로로 지키고, 칩 바깥(선폭 · 단자 · 다이오드 · 퓨즈)은 5.5A 기준으로 만든다.**

## 2. 블록도

```
12V 어댑터(+/−) ─ J1 ─ [역접속 보호] ─┬─ 벌크 캡 ─ L298N VS ─ OUT1~4 ─ J2·J3 ─ 모터 ×2
                                       │
                                       └─ 5V 레귤레이터 ─┬─ ATmega328P (VCC · AVCC)
                                                         ├─ L298N VSS (로직)
                                                         ├─ J(거리센서) VIN ─ VL53L0X
                                                         └─ 3.3V LDO ─ J(nRF) VCC ─ nRF24L01+

ATmega328P ─ 제어 6선 ─ L298N (ENA · IN1~IN4 · ENB)
           ─ SPI 3선 + CE · CSN ─ J(nRF)
           ─ I2C 2선 ─ J(거리센서)
           ─ UART(TX · RX · DTR) ─ J(UART 헤더)      ← 업로드용, 5V 핀은 연결하지 않는다
           ─ ISP 6선 ─ J(ISP 헤더)                    ← 부트로더 굽기용
```

## 3. 전원 트리 (외부 전원은 12V 하나)

| 레일 | 만드는 곳 | 쓰는 곳 | 비고 |
|---|---|---|---|
| 12V | 어댑터 +/− → (PCB 밖 퓨즈 · 스위치) → J1 → 역접속 보호 → 벌크 캡 | L298N VS(4번 핀) · 5V 레귤레이터 입력 | 모터 전류 경로, 최대 5A (어댑터 한계) |
| 5V | L7805급 TO-220 (입력 0.33µF · 출력 0.1µF) | ATmega328P VCC·AVCC · L298N VSS(9번 핀) · 거리센서 VIN · 3.3V LDO 입력 | 부하 합계는 아래 표 |
| 3.3V | 5V → AP2112K-3.3 (SOT-25) | nRF24L01+ PA/LNA VCC | 입력 최대 6V, 출력 600mA, 입·출력 1µF 세라믹. nRF 커넥터 옆 10µF + 100nF. **EN(3번)은 VIN에 직접 연결** (끄고 켤 일이 없으면 그렇게 하라는 부품 페이지 안내, 비워 두지 않는다) |
| GND | 12V 입력 GND 단자에서 시작 | 전부 | 별 접속(10장) |

**5V 부하 합계** (모터는 12V에서 L298N으로 바로 가므로 포함하지 않는다. 3.3V LDO는 전류를 그대로 통과시키므로 nRF 전류가 5V에서 같은 양으로 빠진다)

| 5V에서 전기를 쓰는 것 | 연속 | 피크 | 근거 |
|---|---|---|---|
| ATmega328P (16MHz, 5V) | 약 10mA | 약 12mA | 8MHz · 5V 전형 5.2mA(요약본 표)를 2배로 환산한 추정 ⚠ |
| L298N 로직 (VSS 9번) | 24mA | 36mA | ST 데이터시트 사본: Ven=H · 입력 LOW 24mA 전형 / 36mA 최대 (입력 HIGH면 7 / 12mA) |
| VL53L0X 모듈 | 약 19mA | 40mA | ST: 레인징 중 19mA. Pololu 캐리어: 평균 10mA · 피크 40mA |
| nRF24L01+ PA/LNA | 약 45mA (수신) | 115~140mA (송신 순간) | 모듈 판매 사양 다수 (최대 송신 115mA 또는 140mA, 수신 45mA) |
| **합계** | **약 100~110mA** | **약 230mA** | 송신은 ms 단위의 짧은 순간 |

참고: L298의 IS(13 / 50mA, 4번 핀)는 12V(VS) 쪽 전류이고 5V 부하가 아니다. 5V 쪽은 ISS(9번 핀)다.

**5V LDO 발열** — P = (입력 − 5V) × 전류

| 입력 | 연속 110mA | 피크 230mA (순간) |
|---|---|---|
| 12V | 0.77W | 1.61W |
| 13.5V (어댑터 무부하 ⚠) | 0.94W | 1.96W |

L7805 TO-220의 Rth(j-a)는 제조사별 65~83°C/W라서 0.8~0.9W면 약 50~78°C 올라간다. 주변 25°C에서 Tj 75~103°C, 케이스 안이면 더 높다. **LDO 유지로 확정** (1~2W 수준이라 벅이 필요한 단계는 아님). 단 방열 처리는 필요하다: 클립형 방열판을 달거나 탭 아래 구리 면적을 넓게 잡는다.

**원칙 3가지**
1. **UART 어댑터의 VCC(5V) 핀은 연결하지 않는다.** 5V가 두 군데서 들어오면 서로 밀어내거나 어댑터가 손상될 수 있다. 업로드할 때도 12V를 켠다.
2. 레귤레이터 입·출력 캡은 데이터시트 권장값을 따른다 (L7805: 입력 0.33µF · 출력 0.1µF ⚠ 제조사별 확인). 값 자체는 관례이고 중요한 건 **레귤레이터 핀 바로 옆**에 두는 것.
3. 퓨즈 · 스위치는 PCB 밖(어댑터선 쪽)에 둔다 (기존 결정). 퓨즈는 **5A 지연형**: PCB 12V 경로(선폭 2.8mm 이상, 6장)의 정격 이하로 맞춘다.

**역접속 보호 — P채널 MOSFET (기본안, 앞선 추천에서 변경)**
- **변경 이유**: 설계 기준이 최대 5A이므로 직렬 쇼트키(VF 약 0.5V 가정)는 약 2.5W를 낸다. L298N · 5V LDO 다음 세 번째 열원이 된다. MOSFET은 Rds(on) 20mΩ 가정 시 약 0.5W다 (⚠ 둘 다 가정값). 후보인 AO4407A(C7379957)는 판매 페이지에 9mΩ@10V로 표기돼 있어 5A에서 약 0.23W(I²R, 25°C 값 기준, 온도가 오르면 더 큼)다.
- **연결**: 드레인 = J1(+) 입력 쪽, 소스 = 12V 레일(부하) 쪽, 게이트 = 저항(10~100kΩ)을 거쳐 GND. 정상 극성이면 몸체 다이오드가 먼저 통하고 Vgs가 약 −11V가 되어 채널이 켜진다. 거꾸로 꽂으면 Vgs≈0이라 꺼지고 몸체 다이오드도 역방향이 된다.
- **부품 조건 (EasyEDA 검색용)**: P-ch, Vds ≤ −30V, Id ≥ 10A, Rds(on) ≤ 30mΩ @ Vgs −10V, Vgs(max) ±20V. 입력이 12~15V라 게이트 제너는 생략 가능하다 ⚠. 후보: AO4407A (SOP-8, 30V · 12A). SOP-8 핀은 1~3 = 소스, 4 = 게이트, 5~8 = 드레인.
- **비교용 대안**: 직렬 쇼트키(5A급)는 부품 1개로 끝나지만 위 발열이 있다. 슬라이드에서 두 방식의 손실을 숫자로 비교한다.

**L298N (Multiwatt-15) 핀**

| 핀 | 이름 | 연결 |
|---|---|---|
| 1 | SENSE A | Rs(0.33Ω · 2W) → GND, NPN 베이스(1kΩ 경유). 6장 전류 제한 회로 |
| 2 · 3 | OUT1 · OUT2 | 모터 A (J2) |
| 4 | VS | 12V 레일 + 벌크 캡 + 100nF |
| 5 | INPUT1 | D2 |
| 6 | ENABLE A | D5 (PWM, 1kΩ 경유) + NPN 컬렉터 |
| 7 | INPUT2 | D3 |
| 8 | GND | GND (+ 방열 탭이 8번 핀에 연결됨) |
| 9 | VSS | 5V + 100nF |
| 10 | INPUT3 | D4 |

**보호 다이오드 8개**: OUT1~OUT4 각각에 대해 (OUT → VS 방향) 1개 + (GND → OUT 방향) 1개. 역기전력을 전원 레일과 GND로 되돌려 보낸다. 데이터시트는 빠른 회복(trr ≤ 200ns) 소자 또는 쇼트키를 권장한다. 전류는 3A급: SS34 (SMA, 40V · 3A, VF 550mV@3A)로 정한다. 하단 4개(GND → OUT)는 애노드를 **보드 GND**에 연결하고 SENSE 노드에는 연결하지 않는다 (역기전력 전류가 Rs를 지나면 전류 제한 회로가 오동작한다).

**부착 커넥터**

| 커넥터 | 핀 | 신호 |
|---|---|---|
| J1 | 스크류 단자대 2P (5.08mm, WJ500V-5.08-2P, 정격 18A 표기) | 12V + / GND |
| J2 · J3 | 스크류 단자대 2P ×2 (같은 정격) | 모터 A · B |
| nRF | 핀 헤더 2×4 | GND · VCC(3.3V) · CE · CSN · SCK · MOSI · MISO · IRQ(미연결) |
| 거리센서 | 핀 헤더 1×4 | VIN(5V) · GND · SCL · SDA |
| UART | 핀 헤더 1×6 | GND · (CTS) · **VCC 미연결** · TX · RX · DTR(100nF 경유 RESET) |
| ISP | 핀 헤더 2×3 | MISO · SCK · MOSI · RESET · VCC · GND |

SPI 3선(SCK · MISO · MOSI)은 nRF 커넥터와 ISP 헤더가 같은 선을 공유한다. 부트로더를 굽는 동안 nRF가 MISO를 붙잡지 않으려면 CSN이 HIGH일 때 nRF의 MISO가 하이임피던스여야 한다. ⚠ nRF24L01+ 데이터시트에서 확인하고, 불안하면 굽는 동안 nRF 케이블을 뺀다.

## 6. 설계 기준 · 계산

**설계 기준: 모터 1개 stall 5.5A** (12V / 2.2Ω 가정)
- 근거: 같은 급(37mm · 12V · 200RPM)인 Pololu 37D의 stall 5.5A. 실제 ZGA37RG 값은 판매 페이지에 없다 (페이지에는 12V · 200RPM · "지속적 전류 100mA"뿐). 이번에는 발주하지 않으므로 실측하지 않고, 비슷한 37mm 12V 기어모터의 stall 전류 중 가장 큰 값(Pololu 37D 12V 전 모델 5.5A, 외삽값. E-S Motor GM37은 2.4A)을 설계 기준으로 고정한다. 실제 모터를 쓰게 되면 권선 저항을 재서 12V / R로 확정한다.
- 12V 입력은 어댑터 5A가 상한이므로 12V 경로는 5A, 모터 출력 경로는 5.5A로 만든다.
- L298N의 절대최대는 DC 2A/채널(반복 피크 2.5A, 비반복 3A)이라 **칩은 5.5A를 견딜 수 없다.** 그래서 칩은 아래 전류 제한 회로로 지키고, 칩 바깥은 5.5A 기준으로 만든다. 선폭은 비용이 들지 않는다.

**선폭** — IPC-2221, 외층, 온도 상승 10°C 기준 (계산값)

| 전류 | 1oz | 2oz |
|---|---|---|
| 1A | 0.30mm | 0.15mm |
| 2A | 0.78mm | 0.39mm |
| 3A | 1.37mm | 0.68mm |
| 5A | 2.77mm | 1.38mm |
| 5.5A | 3.15mm | 1.58mm |
| 6A | 3.56mm | 1.78mm |

설계값: **12V 메인 경로 ≥ 2.8mm, 모터 출력 경로 ≥ 3.2mm, 모두 폴리곤으로** 처리한다. 신호선은 0.25~0.3mm. IPC 식은 보수적인 근사이므로 판단 기준으로만 쓴다.

**칩이 실제로 받는 전류 (추정)** — L298의 포화전압(2A에서 합계 전형 3.7V, 최대 4.9V)이 전류를 스스로 깎는다. R=2.2Ω에서 100% 듀티 stall은 약 2.9A다 (선형 근사). ngspice 간이 시뮬레이션(모터 L=2mH 가정)에서 PWM 78% stall은 피크 약 2.3A, 평균 약 1.5A였다. 5.5A가 칩을 통과하지는 않지만 2A DC 한계 근처이므로 보호가 필요하다. (모든 값이 가정에 기대고 있어 ⚠)

**전류 제한 회로 (소자만, 펌웨어 없음)**
- **채널당 부품**: Rs 0.33Ω 2W (SENSE 핀 → GND), NPN 1개, 저항 1kΩ 2개.
  - Rb 1kΩ: SENSE 노드 → NPN 베이스.
  - NPN: 컬렉터 = L298N Enable 핀, 이미터 = GND.
  - Rg 1kΩ: MCU PWM 핀 → Enable 핀 사이에 직렬로 넣는다. NPN이 MCU 출력을 이기고 Enable을 끌어내리게 하는 저항이다.
- **동작**: 모터 전류가 Rs에 전압(I × Rs)을 만들고, 약 0.65V(NPN의 Vbe)를 넘으면 NPN이 켜져 Enable이 LOW가 된다. 브리지가 꺼져 전류가 보호 다이오드로 빠지고, 전류가 줄면 NPN이 꺼져 다시 켜진다. 이 반복으로 피크 전류가 임계값 근처에 묶인다.
- **임계값** ≈ 0.65V / Rs. Rs=0.33Ω이면 약 2A, 0.47Ω이면 약 1.4A. NPN의 Vbe는 개체 차이와 온도(약 −2mV/°C)로 달라지므로 **오차 ±20% 이상**으로 본다 ⚠.
- **ngspice 간이 시뮬레이션** (이상 스위치 · L=2mH 가정 · 열 모델 없음): 

| | 모터 피크 | 모터 평균 |
|---|---|---|
| 제한 회로 없음 | 2.31A | 1.54A |
| Rs 0.33Ω | 2.13A | 1.43A |
| Rs 0.47Ω | 1.51A | 1.05A |

  제한 회로가 피크를 임계값에 맞춰 낮추는 방향은 확인했다. SENSE 노드 전압은 최대 약 0.76~1.05V로 데이터시트 센싱 전압 범위(−1~2V, 사본 기준 ⚠) 안이다. 시뮬레이션이 간이라 **실물 검증 전까지 설계 안이다.**
- **한계 ①: 지속 stall.** 제한 중에도 칩은 채널당 약 1.5A × 3.3V ≈ 5W, 두 채널이면 약 10W(추정)가 열이 된다. 방열판(약 17°C/W)이 있어도 수 초 이상 이어지면 130°C를 넘을 수 있다. L298에는 과열 보호가 있다 (ST 데이터시트 특징 항목, DigiKey 사양표의 보호 항목에도 Over Temperature). 다만 동작 온도 · 복귀 조건은 확인하지 못했다 ⚠. 보호가 있어도 가열 · 차단을 반복하는 사용은 설계 의도가 아니다. 이 회로는 순간 stall과 출발 피크를 누그러뜨리는 용도이고, 막힌 채 오래 두는 것을 막지는 못한다.
- **한계 ②: Enable 단속 주파수.** Enable 반응 지연(수 µs)에서 단속 주파수가 수십 kHz가 될 수 있고 스위칭 손실이 늘어난다. 데이터시트의 전류 전환(commutation) 주파수 규격은 25kHz(전형) · 40kHz(최대)(사본 기준)라 이 근처면 규격에 닿는다. 실측 필요 ⚠.

**보호 계층 (전부 소자)**

| 보호 | 막는 것 | 못 막는 것 |
|---|---|---|
| 퓨즈 5A 지연형 (PCB 밖) | 단락, 배선 화재 | stall (끊기지 않음) |
| 역접속 P-MOSFET | 어댑터 극성 실수 | |
| 전류 제한 (Rs + NPN) | stall 피크, 출발 전류 | 수 초 이상 지속되는 stall |
| 보호 다이오드 8개 | 모터 역기전력 | |
| 방열판 | 열 축적 시간 확보 | 지속 stall |
| 벌크 캡 1000µF | ms 단위 전압 변동 (PWM 리플) | 수십 ms 이상 부족: ΔV = I·Δt/C라서 1A 부족이 1ms만 있어도 1000µF에서 1V다 |

**12V 처짐**: 두 바퀴가 동시에 막히면 합계가 어댑터 5A를 넘어 12V가 처질 수 있고, 입력이 7V 아래로 가면 5V LDO가 무너져 MCU가 리셋될 수 있다. 전방 충돌은 VL53L0X가 30cm에서 전진을 막으므로 위험이 낮다고 판단한다 (사용자 판단). 후진 · 측면 · 센서보다 낮은 장애물은 막지 못한다.

**L298N 발열 (정상 주행)** — 데이터시트 전형 포화전압: 1A에서 소스 1.35V + 싱크 1.2V, 2A에서 2.0V + 1.7V
- 채널당 1A: 2.55W, 두 채널 5.1W.
- Multiwatt-15의 Rth(j-amb) 최대 35°C/W를 그대로 쓰면 Tj 상승이 약 178°C. 동작 접합온도 상한은 130°C이므로 **방열판 없이는 불가**.
- 주변 40°C 기준 방열판 + 접촉면 ≲ 14°C/W가 필요하다 (Rth(j-c) 3°C/W 포함 시 Rth(j-amb) ≲ 17°C/W).
- 모터 전류 가정(채널당 1A)이므로 실제 모터 값으로 다시 계산한다.

## 7. 코드 수정 항목 (Mega → 328P) — 컴파일로 확인함

대상: RC_CAR 저장소 `firmware/v4/vehicle_mega/vehicle_mega.ino` (차량 최종 버전).

| 항목 | 수정 |
|---|---|
| IN1~IN4 | D22·23·24·25 → D2·D3·D4·D9 |
| SS 핀 출력 설정 | D53 → D10 (`pinMode(10, OUTPUT); digitalWrite(10, HIGH);`) |
| 상태 LED | D13 → A0. **328P에서 D13은 SPI SCK**라서, Mega 보드 LED(D13)를 그대로 쓰면 SCK 선과 충돌한다. LED를 A0에 달고 핀 번호를 바꾼다. |
| 나머지 | 그대로 (ENA D5 · ENB D6 · CE D7 · CSN D8. SPI · I2C는 라이브러리가 핀을 맞춘다) |

**컴파일 결과** (avr-gcc 7.3, Arduino AVR 코어 + RF24 + Pololu VL53L0X 최신판, `-Os`, 보드 = Arduino Uno / ATmega328P)

| | 328P (위 수정 적용) | Mega 2560 (원본) |
|---|---|---|
| 플래시 | 11,130 B (34.0%) | 13,616 B (5.2%) |
| RAM | 507 B (24.8%) | 1,005 B (12.3%) |

328P에 충분히 들어간다. 플래시 66%, RAM 75%가 남는다. 사용자 PC의 Arduino IDE 라이브러리 버전에 따라 수 %는 달라질 수 있다.
수정 5줄은 실제로 반영해 컴파일까지 확인했다 (사용량은 수정 전과 같다). 동작(모터 · 무선 · 거리센서)은 실물이 없어 확인하지 못했다.

**PWM 주파수**: Mega의 D5·D6은 약 490Hz, 328P의 D5·D6은 약 980Hz다. 모터 소리 · 속도감이 약간 달라질 수 있다. 980Hz는 L298 데이터시트의 전류 전환 주파수 규격(25kHz 전형 · 40kHz 최대)보다 한참 낮아 문제 없다고 판단한다. (v0.3에 적었던 '1kHz급 기재' 메모는 데이터시트 사본에서 확인되지 않아 뺐다.)
**nRF MISO 마진**: nRF가 내보내는 HIGH(약 VDD−0.3V = 3.0V)와 328P(5V)의 입력 HIGH 문턱(0.6×VCC = 3.0V)이 거의 같다. Arduino Uno에서도 흔히 쓰는 조합이라 대개 동작하지만 마진이 없다 ⚠.

## 10. 레이아웃 원칙

- **GND**: 12V 입력 GND 단자를 시작점으로 하는 별 접속. 모터 귀환 전류(L298N GND 8번 핀)가 MCU 쪽 GND 구간을 지나지 않게 한다. 뒷면은 GND 면.
- **캡**: 디커플링은 IC 전원 핀 바로 옆, 벌크 캡은 L298N VS 쪽.
- **L298N**: 방열판을 달 수 있게 보드 가장자리에 두고 12V·모터 선을 짧게 한다.
- **nRF 커넥터**: 케이블이 나가는 보드 가장자리에, SPI 선은 짧게 (모듈은 보드 밖이므로 케이블 길이를 짧게, 약 10~15cm 이하 권장 ⚠).

## 11. 확인 필요 / 미확정

**결정 (사용자 확인 대기)**: LDO 유지(방열 처리), TQFP-32. 역접속 보호는 **직렬 쇼트키에서 P-MOSFET으로 변경**했다 (5A 설계 기준에서 쇼트키 발열이 약 2.5W). 이의가 있으면 3장의 쇼트키 대안으로 되돌린다.

**열린 항목**
1. ~~모터 stall 실측~~: 하지 않기로 했다. 비슷한 모터의 최악값 5.5A를 설계 기준으로 고정한다. 실제 모터를 쓰게 되면 R을 재서 12V / R로 바꾸고 선폭 · 퓨즈를 다시 확인한다.
2. **전류 제한 회로는 간이 시뮬레이션만 거쳤다**: 이상 스위치, 모터 L=2mH 가정, NPN Vbe 오차 ±20% 이상. 실물 검증 전까지 설계 안.
3. **지속 stall(수 초 이상)은 못 막는다**: L298에 과열 보호는 있으나 동작 온도 사양은 미확인이다. 보호 소자만으로 막으려면 래치 회로(비교기 + 타이머) 또는 펌웨어가 필요하다 (범위 밖으로 둠).
4. 핀 번호(TQFP-32, Multiwatt-15)를 EasyEDA Symbol Pin 번호와 대조 (EasyEDA 실습 중 확인).
5. nRF MISO의 하이임피던스 여부(ISP와 SPI 선 공유) · HIGH 출력(약 3.0V)과 328P 입력 문턱(3.0V)의 마진 없음 ⚠.
6. ~~PWM 주파수~~: 해소 (v0.4). 980Hz는 규격(25 / 40kHz) 아래. 단 전류 제한 회로의 단속 주파수는 실측 전까지 열려 있다 (6장 한계 ②).
7. 5V 부하 중 328P 전류는 요약본 값의 2배 환산 추정이다 (나머지는 데이터시트 · 판매 사양 값).
8. 328P 컴파일은 통과했지만 모터 · 무선 · 거리센서의 실제 동작은 확인하지 못했다.
9. 조종기 전원 방식(USB 또는 12V)은 미정이다.

**닫힌 항목**: 328P 용량(7장), nRF 모듈 종류(PA/LNA), 5V 부하 합계(3장), 레귤레이터 종류(LDO), MCU 패키지(TQFP-32). v0.4에서 추가: 크리스털 로드 캡, 단자대 정격, 쇼트키 부품, P-MOSFET 후보, AP2112K EN 처리, L298 과열 보호 유무, PWM 980Hz, 부품 LCSC 번호 (parts-confirmed.md), 모터 stall 기준(실측 없이 5.5A 고정).
