# 설계 결정 로그

2026-11-14 ~ 11-15 Claude와의 작업 세션에서 나온 결정과 근거를 정리한 것이다. **대화 원문이 아니라 정리본**이다. 최신 설계 내용은 [`spec-v0.3.md`](spec-v0.3.md)가 기준이다.

## 목표

미제연 11월 미니프로젝트(RC카) PCB 특강에서 쓸 **모델 PCB**를 설계한다. 산출물은 (A) 정답 예시 자료(사양서 · 넷리스트 · BOM)와 (B) KiCad 파일이다. A의 사양서는 v0.3까지 썼고 B는 시작하지 않았다.

## 확정된 결정

| # | 결정 | 근거 |
|---|---|---|
| 1 | 쉴드형은 쓰지 않고 **통합형**(점퍼선 · Arduino · L298N 모듈 없이 한 장)으로 한다 | 쉴드는 Mega 핀 배치에 묶이고, 목표가 "컴팩트"다 |
| 2 | MCU는 **ATmega328P(TQFP-32)** 로 Mega를 대체한다 | 차량 펌웨어가 328P에 들어가는지 avr-gcc로 확인 (플래시 34%, RAM 25%) |
| 3 | 모터 드라이버는 **L298N IC**로 모듈을 대체한다 | 기존 모듈과 같은 칩이라 코드 · 동작이 같다 |
| 4 | nRF24L01+ PA/LNA와 VL53L0X는 **PCB 밖**(커넥터 + 케이블) | 안테나 위치 문제, 거리센서는 앞쪽에 달아야 함 |
| 5 | 외부 전원은 **12V 한 계통**. 5V는 L7805급 LDO, 3.3V는 AP2112K | 5V 부하 약 100~110mA(피크 230mA)라 LDO 발열이 1~2W 수준 |
| 6 | 퓨즈 · 스위치는 **PCB 밖** | 어댑터선 쪽에 두는 기존 결정 |
| 7 | 설계 기준은 **모터 1개 stall 5.5A**(최악 가정) | 사용자 지시. 같은 급 모터의 stall 값, 실측 전까지 가정 |
| 8 | 보호는 **소자(저항 등)와 회로 위주**, 펌웨어 보호는 제외 | 사용자 지시 |
| 9 | 12V 처짐으로 MCU가 리셋될 위험은 **수용** | VL53L0X가 30cm에서 전진을 막는다는 사용자 판단 (후진 · 측면은 못 막음) |
| 10 | LDO 유지, TQFP-32 | 사용자가 부품 확정 |
| 11 | 역접속 보호는 **P채널 MOSFET** (직렬 쇼트키에서 변경) | 5A에서 쇼트키는 약 2.5W, MOSFET은 약 0.5W (둘 다 가정값). 사용자 이의 없으면 확정 |
| 12 | 조종기 보드는 확장 과제, 실습은 4단계(MCU 코어 → 전원 → 구동 → 커넥터 · 배선 · DRC) | 이론 ①~④와 대응 |

## 핵심 설명: stall 전류

- 돌고 있는 모터는 **역기전력**이 전원 전압을 일부 상쇄해 전류가 작다. 바퀴가 막히면 역기전력이 사라져 전류가 I = V / R로 커진다 (12V / 2.2Ω ≈ 5.5A).
- 브레드보드 차량에서 문제가 없었던 이유: 같은 L298N 칩과 같은 한계를 쓰고, 모터 전류는 모듈 자체 단자와 패턴만 지나가며, stall이 드물고, L298의 포화전압이 전류를 스스로 깎기 때문이다.
- PCB에서 달라지는 점: 같은 칩이지만 **선폭 · 커넥터 · 다이오드 · 퓨즈 · 방열**을 이제 설계자가 정한다.
- 보호 대응: 퓨즈는 단락 · 배선 화재용(stall에서는 안 끊김), 전류 감지 저항 + NPN이 피크를 제한, 직렬 제한 저항은 발열이 커서 채택하지 않음. 요지는 "저항을 달면 나아진다"가 아니라 "저항으로 전류를 읽고 끊는다"이다.

## 정정 이력 (초기 설명 중 틀렸던 것)

| 틀렸던 내용 | 바로잡은 내용 |
|---|---|
| MAX_PWM이 stall 보호가 된다 | 평균 전압을 약 78%로 낮출 뿐이라 stall 전류는 약 4.3A(5.5A 기준)로 여전히 크다 |
| 5.5A > 2A는 PCB만의 문제 | 기존 모듈에도 같은 L298N이 있다. 달라지는 건 칩 바깥 경로를 누가 설계하느냐다 |
| 퓨즈로 stall을 막는다 | 4A 퓨즈는 약 3A stall에서 안 끊기고, 2A 퓨즈는 정상 구동에서 끊긴다. 퓨즈는 단락용이다 |
| 직렬 쇼트키 3A로 역접속 보호 | 5A 기준에서 용량 부족 + 발열 → P-MOSFET으로 변경 |
| L298의 13 / 50mA가 5V 로직 전류 | 그 값은 12V(VS) 쪽 IS다. 5V 쪽 ISS는 24 / 36mA |
| 모터 판매 페이지에 "13단", "AI 요약" 언급 | 확인하지 못한 내용이었다. 실제 표기는 12V · 200RPM · "지속적 전류 100mA"뿐 |
| 코드 "수정 6곳" | 실제 변경 5줄 |
| 시뮬레이션 초기 버전 | 스위치 모델 오류로 비현실적 스파이크(최대 12.8A). 인에이블 지연(3µs)과 싱크 스위치를 넣어 고침 |

## 미해결 항목

사양서 11장 참고. 요약:

1. 모터 권선 저항 실측 → 실제 stall 전류
2. 전류 제한 회로의 실물 검증 (지금은 간이 시뮬레이션뿐)
3. 수 초 이상 지속되는 stall은 소자만으로 못 막음 (L298 과열 보호 유무 미확인)
4. 핀 번호와 EasyEDA / KiCad 심볼 대조
5. nRF MISO 공유 · 전압 마진 (ISP와 SPI 선 공유)
6. PWM 980Hz와 L298N Enable 주파수 사양
7. 모터 · 무선 · 거리센서 실제 동작 확인
8. 조종기 전원 방식
