# 전류 제한 회로 간이 시뮬레이션

L298N 한 채널(모터 1개)에 Rs + NPN 전류 제한 회로를 붙였을 때 PWM 78% stall 전류가 어떻게 달라지는지 본 ngspice 모델이다.

## 실행

```bash
ngspice -b no_limiter.cir
ngspice -b limiter_rs033.cir
ngspice -b limiter_rs047.cir
```

ngspice 42에서 실행했다. 출력의 `ipk` · `iavg`는 모터 전류의 피크 · 평균(5~12ms 구간), `vsmax` · `vsmin`은 SENSE 노드 전압이다.

## 결과

| 파일 | 조건 | 모터 피크 | 모터 평균 | SENSE 최대 |
|---|---|---|---|---|
| `no_limiter.cir` | 제한 회로 없음 | 2.31A | 1.54A | 0.76V |
| `limiter_rs033.cir` | Rs 0.33Ω + NPN | 2.13A | 1.43A | 1.05V |
| `limiter_rs047.cir` | Rs 0.47Ω + NPN | 1.51A | 1.05A | 1.01V |

## 모델의 한계 (결과를 그대로 믿지 말 것)

- 스위치는 이상 스위치, L298 포화전압은 `1.4V + 1.15Ω` 선형 근사다.
- 모터는 R = 2.2Ω(12V / 5.5A 가정), L = 2mH 가정이다. 실제 모터 값이 아니다.
- 인에이블 반응 지연은 약 3µs(RC)로 넣었다. 실제 L298 값과 다를 수 있다.
- NPN은 2N3904급 일반 모델이다. Vbe의 개체 차이와 온도 변화는 반영하지 않았다.
- 열 모델이 없다. 지속 stall에서 칩이 얼마나 뜨거워지는지는 이 모델로 알 수 없다.
- 한 채널만 모델링했다. 두 채널 동시 stall이나 12V 처짐은 포함하지 않았다.

피크를 낮추는 방향은 확인했지만, 실물에서 같은 크기로 동작한다는 증거는 아니다.
