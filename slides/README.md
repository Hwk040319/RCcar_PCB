# slides

특강 덱 `PCB설계_RC카 .pptx` (486장, 파일명에 `.pptx` 앞 공백이 있다)를 두는 폴더다.

- 슬라이드 제목 목차: [`../docs/deck-outline.md`](../docs/deck-outline.md)
- 실습 1~17(덱 390–457) 구간의 스크린샷 자리는 비어 있다. 강사가 EasyEDA를 직접 돌린 뒤 채운다 ([`../docs/handson-checklist.md`](../docs/handson-checklist.md)).
- 덱의 메뉴 경로는 실제 EasyEDA 화면을 확인하기 전이다.
