## 11-18 최종본 (CODEPLANT 디자인, 181장)

`PCB설계_RC카_CODEPLANT_v0.5.pptx`는 동료 강사가 발표하는 최종본이다. 첨부 받은 CODEPLANT 167장 레이아웃을 기준으로 회로 기초 9장(전압 · 전류 · 단위 · 식 · 부품 기호 · 디지털 신호 · IC)과 보강 5장(12V 하강 → 리셋, Rs 동작 순서 · 값과 한계, 자동 배선 2장, ISP / UART)을 더했고, 슬라이드마다 발표자 노트에 말할 내용을 적었다. 위 486장 덱은 원본 자료로 그대로 둔다. GitHub 연동 도구로는 pptx를 올릴 수 없어 저장소에는 아직 없다 (강사가 Add file → Upload files로 올린다). 남은 빈칸은 [`../docs/handoff-lecture.md`](../docs/handoff-lecture.md).
